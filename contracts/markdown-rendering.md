# Markdown rendering profile

管理预览、兼容阅读与独立阅读共用的输出约定：CommonMark 基础 + GFM 表格、任务列表、删除线。
正文仍以原始文本字符串保存（Markdown/HTML/TXT/JSON/XML），不保存编辑器 JSON 状态，不改变修订与发布语义。

- 表格限单表头，禁止非 GFM 的跨列扩展；缺列补齐、多列截断，与 Markdown 编辑器输出匹配。
- 任务列表在编辑端可勾选并更新 Markdown；预览/阅读端输出静态 ☑ / ☐，不产生可提交的表单控件。
- 删除线保留 del 元素；HTML 继续经过现有 Jsoup 白名单，脚本、事件属性、危险协议不放行。
- 数学、脚注、嵌入 HTML 等不能可靠往返的可视化输入保留源码模式。原始正文不因打开/切换而被改写。
- 各部署构件保留独立依赖；共同样例 `markdown-profile.md` 由预览与两条阅读路径的测试读取验证，避免界面支持与交付输出漂移。
